# 前端切换说明：unified-agents.html（案卷控制台）

> 记录时间：2026-08-27  
> 项目路径：`D:\dsh-test\finance agent`  
> 目标：把主前端从默认的 `formal-console.html`（杂志风）切换为 `prototype-research-ui/unified-agents.html`（案卷控制台研究台）



---

## 一、背景：项目里其实有两套前端、两个后端

前端"能不能跑"取决于它背后接的是**哪个 FastAPI 入口**，而这两个入口暴露的路由完全不同：

|           | `formal-console.html`                  | `unified-agents.html`                        |
| --------- | -------------------------------------- | -------------------------------------------- |
| 视觉风格      | 米黄纸质 `#eee9dc` + 橙 `#ef5b2a`，杂志/编辑风    | 深色「案卷控制台」研究工作台                               |
| 后端入口      | `backend.formal_app:create_formal_app` | `backend.app:create_app`                     |
| 数据库       | Postgres + 行级安全 + 登录鉴权                 | SQLite（内置 `Repository`），无鉴权                  |
| 后端特点      | **刻意不暴露**研究路由（安全/商业化考量）                | 暴露 `/api/securities`、`/api/research`、SSE 事件流 |
| Docker 默认 | ✅ 默认服务它                                | ❌ 原本不服务，本次才切过去                               |

> 结论：之前觉得 `formal-console.html`"长得很怪"不是 bug，是刻意设计；而 `unified-agents.html` 是另一套、更"正经"的研究台。要让它可用，**核心不是改 HTML，而是把后端切成 `backend.app`**。

---

## 二、请求链路（改完之后）

```
浏览器 https://localhost:8443/
   │   根路径 index.html 做 meta-refresh → unified-agents.html
   │   （HTML 由 Caddy 从 bind-mount 的 /srv 直接返回，无构建步骤）
   ▼
Caddy 反向代理 :8443   （CSP 已放宽，允许内联脚本 + jsdelivr CDN）
   │   /api/* → api:8000
   ▼
api 容器  uvicorn backend.app:create_app  :8000
   │   研究路由全部注册；数据落在容器内的 SQLite
   ▼
研究任务：POST /api/research → 任务进入 running（mock/合成，自包含于 api 进程）
          SSE  /api/research/{id}/events → 实时事件流，前端渲染时间线
```

要点：

- 页面是**纯静态文件**（内联 `<style>` + `<script>`），被 bind-mount 挂进 Caddy 的 `/srv`。改 HTML 即时生效，连 Caddy 都不用重启。
- 后端代码**烘焙在镜像里**，所以切后端入口需要重建/重创 api 容器（见第四节）。

## 三、改动清单（共 4 处）

### ① 切换后端入口 `compose.yaml`

文件：`compose.yaml`（约第 85 行，`api` 服务的 `command`）

```yaml
# 改前（Docker 默认，对应 formal-console.html）
command: [python, scripts/container_entrypoint.py, uvicorn, backend.formal_app:create_formal_app, --factory, --host, 0.0.0.0, --port, "8000", --proxy-headers, --forwarded-allow-ips, "*"]

# 改后（对应 unified-agents.html）
command: [python, scripts/container_entrypoint.py, uvicorn, backend.app:create_app, --factory, --host, 0.0.0.0, --port, "8000", --proxy-headers, --forwarded-allow-ips, "*"]
```

### ② 同步镜像默认 CMD `Dockerfile`

文件：`Dockerfile`（第 19 行）

```dockerfile
# 改前
CMD ["uvicorn", "backend.formal_app:create_formal_app", "--factory", "--host", "0.0.0.0", "--port", "8000"]
# 改后
CMD ["uvicorn", "backend.app:create_app", "--factory", "--host", "0.0.0.0", "--port", "8000"]
```

> 目的：即使不带 compose（直接 `docker run` 镜像）启动，也默认跑研究原型，避免不一致。

### ③ 根路径重定向 `prototype-research-ui/index.html`

```html

<meta http-equiv="refresh" content="0; url=./formal-console.html">

<meta http-equiv="refresh" content="0; url=./unified-agents.html">
```

### ④ API 地址同源化 `prototype-research-ui/unified-agents.html`

文件：`unified-agents.html`（约第 354 行）

```js
// 改前：指向本地开发服务器，容器内不通且触发 CORS/CSP
const API_BASE = 'http://127.0.0.1:8780/api';
// 改后：走 Caddy 反代，与页面同源
const API_BASE = '/api';
```

### ⑤ Caddy CSP 放宽（必须，否则白屏） `infra/caddy/Caddyfile`

文件：`infra/caddy/Caddyfile`（约第 14 行）

该页是**内联 CSS/JS** 且从 **jsdelivr CDN 引 ECharts**，原 CSP 的 `script-src 'self'` 会直接拦截导致白屏。放宽如下：

```
Content-Security-Policy "default-src 'self'; connect-src 'self' https://localhost:9443; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; font-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self' https://localhost:9443; frame-ancestors 'none'"
```

> 仅 `style-src` / `script-src` 两处变更：`'unsafe-inline'` + 放行 `https://cdn.jsdelivr.net`。这是为迁就原型页的妥协，技术债见第五节。

## 四、生效方式

HTML 与 CSP 是 bind-mount / 配置重载即可，后端入口切换需重创容器（**复用现有镜像，无需重新 build**）：

```bash
cd "D:\dsh-test\finance agent"

# 后端入口切换：重创 api 容器
docker compose up -d --force-recreate api

# CSP 重载：重启 Caddy
docker compose restart caddy
```

> 验证容器内实际启动模块（排查 404 的杀手锏）：
>
> ```bash
> docker compose exec api sh -c "cat /proc/1/cmdline | tr '\0' ' '"
> # 期望看到：... uvicorn backend.app:create_app --factory ...
> ```

## 六、已知遗留 / 技术债

1. **ECharts 加载策略（已加固为本地优先 + CDN 兜底）**
   页面现以 `<script src="./echarts.min.js" onerror=...>` 加载：若 `prototype-research-ui/echarts.min.js` 存在则用本地（离线可用），否则自动回退到 `https://cdn.jsdelivr.net`。
   *彻底离线化*：在能联网的机器上执行下面任一条，把文件放到 `prototype-research-ui/echarts.min.js` 即可，无需改代码：
   ```powershell
   # PowerShell（本机有网时）
   Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js" -OutFile "D:\dsh-test\finance agent\prototype-research-ui\echarts.min.js"
   ```
   ```bash
   # 或 Git Bash / WSL
   curl -fsSL https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js -o "/d/dsh-test/finance agent/prototype-research-ui/echarts.min.js"
   ```
   放好后图表区即全程本地渲染，不再受外网影响；此时 CSP 里的 `https://cdn.jsdelivr.net` 可收回（但保留也无害）。
2. **当前是 mock 研究模式**  
   未配置 `DEEPSEEK_API_KEY`，研究产出为合成内容。  
   *改进*：设置 `DEEPSEEK_API_KEY` + `FINSCOPE_RESEARCH_MODE=deepseek`，重启 api 容器即可接真实联网研究。
3. **CSP 放了 `'unsafe-inline'`（安全债）**  
   为迁就内联脚本原型页的妥协。若将来把 CSS/JS 拆成外部文件，应收紧回 `'self'`。
4. **切换依赖改 compose 文件（运维债）**  
   频繁在 `formal_app` / `backend.app` 之间切换时，每次都得改 `compose.yaml` 第 85 行 + `Dockerfile` 第 19 行。  
   *改进*：给 `container_entrypoint.py` 加一个环境变量开关（如 `FINSCOPE_APP_MODULE`），`compose.yaml` 用 `${FINSCOPE_APP_MODULE:-backend.app:create_app}` 引用，避免改文件。
