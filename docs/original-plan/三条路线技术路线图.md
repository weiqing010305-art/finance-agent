# 三条 AI 金融项目路线 · 技术路线图

> 目标：从零做出三个可写进简历的 AI 金融项目，三条线共享同一套 LLM / Agent 底座，通过「复用 tool 函数」串联。

---

## 共享底座（三条线通用）

| 能力 | 工具 | 说明 |
|------|------|------|
| 语言 | **Python 3.10+** | 统一开发语言 |
| Agent 框架 | **Strands Agents SDK** | `pip install strands-agents`；模型驱动，少写编排 |
| 模型层（模型无关） | **Ollama**（本地 qwen2.5:7b，免 key）→ **DeepSeek / Claude / GPT** | 本地调试、云端上线，代码几乎不动 |
| 开发环境 | venv + VS Code | 隔离依赖 |

> 主线 2 不用 Strands，纯工程；主线 1、3 用 Strands 当「AI 自己决定步骤」的壳。

---

## 主线 1：AI 财报分析助手（RAG）
**目标**：上传财报 PDF → 抽取利润/现金流/风险 → 提问带原文页码引用 → 多年对比
**简历词**：RAG / LLM 应用 / 文档智能
**对标**：FinGPT 应用层，只做财报做到极致

### 阶段 1：最小可用 MVP（先跑通 RAG 底座）
| 环节 | 工具 | 作用 |
|------|------|------|
| PDF 解析 | **PyMuPDF(fitz)** 或 **pdfplumber** | 提取文字 + 页码 |
| 切片 | 自写（按页/段切） | 每块带 `page` 元数据 → 页码引用源头 |
| Embedding | **sentence-transformers**（BAAI/bge-small-zh-v1.5，本地免费）或 OpenAI text-embedding | 文字变向量，按语义搜 |
| 向量库 | **Chroma**（本地、零配置，入门首选） | 存向量、按相似度检索 |
| Agent | **Strands Agent** | 模型驱动循环 |
| 模型 | Ollama qwen2.5:7b | 免 key 起步 |
| 护栏 | **Hook** | 没写 `[Pxx]` 引用就拦下保存 |
| Prompt | System Prompt | 财报助手人设 + 成功标准（带页码、不编造） |

### 阶段 2：增强（拉开差距）
| 环节 | 工具 | 作用 |
|------|------|------|
| 重排 | **BAAI/bge-reranker-v2-m3** | 先粗捞 20 段再精挑 3 段，提准 |
| 多模态 | pdfplumber 提取图表 + **Qwen-VL / Claude** 读图 | 读柱线图里的数字/趋势，带页码 |
| 多年对比 | 长期记忆：**Chroma 多 collection / pgvector** | 存各年指标，跨会话对比 |
| 上下文工程 | 自管理上下文拼盘 | 拼好 Prompt+检索原文+历史 |

### 阶段 3：生产化
| 环节 | 工具 | 作用 |
|------|------|------|
| 评估 Eval | 自建测试集（问题+标准答案+页码），规则断言打分 | 验证引用完整率/数字准确率 |
| 界面 | **Streamlit / Gradio** | 上传 PDF + 问答 |
| 服务化 | **FastAPI** | 挂成 API |
| 追踪 | Strands tracing / LangSmith | 查每步调了啥 |
| 成本路由 | 检索走小模型、总结走大模型 | 省钱 |

## 主线 2：股票分析平台（工程化）
**目标**：akshare 行情 + 技术指标(MACD/RSI/均线) + 回测 + Streamlit 看板
**简历词**：API / 数据分析 / 可视化 / 工程化
**注意**：这条线**不用 Strands**，纯数据工程；只有「自然语言问数据」可选层才用

### 阶段 1：数据层
| 环节 | 工具 | 作用 |
|------|------|------|
| 行情/财务 | **akshare**（免费，A 股）/ **tushare**（更全，需积分） | 拉数据 |
| 存储缓存 | **SQLite / PostgreSQL** | 定时任务拉数缓存，减少重复请求 |

### 阶段 2：分析引擎
| 环节 | 工具 | 作用 |
|------|------|------|
| 指标计算 | **pandas + numpy + TA-Lib** | MACD/RSI/KDJ/均线 |
| 回测 | **backtrader**（经典）/ **vectorbt**（向量化快）/ 自写 | 策略回测 |

### 阶段 3：看板
| 环节 | 工具 | 作用 |
|------|------|------|
| 界面 | **Streamlit** | 交互看板 |
| 图表 | **Plotly** | 交互 K 线 / 指标图 |
| 可选 AI 层 | Strands + 主线 2 行情函数 | 自然语言问数据（仅这层用 Strands） |

## 主线 3：股票研究 Agent（多 Agent 编排）
**目标**：一句话「分析腾讯」→ 自动跑股价/新闻/财报/评级 → 汇总报告
**简历词**：Agent / 工具调用 / 多步推理
**复用**：主线 1 的 `retrieve` 工具 + 主线 2 的行情/指标函数

### 阶段 1：编排骨架
| 环节 | 工具 | 作用 |
|------|------|------|
| 框架 | **Strands agents-as-tools 模式** | 总管 Agent 调专家 Agent |
| 模型 | 同主线 1 | — |
| 总管 Agent | Strands Agent | 收「分析腾讯」，自己决定调用顺序 |

### 阶段 2：专家工具（复用前两线）
| 专家 | 工具来源 |
|------|----------|
| 股价工具 | 主线 2 的 akshare 行情函数（包成 `@tool`） |
| 财报工具 | 主线 1 的 `retrieve(pdf, query) -> {text, page}` |
| 新闻工具 | akshare 财经新闻 / 东方财富快讯 |
| 评级工具 | akshare 机构评级 |

### 阶段 3：产出与合规
| 环节 | 工具 | 作用 |
|------|------|------|
| 输出 | 结构化报告（Markdown / JSON） | 可解析、可追溯 |
| Handoff | Strands Handoffs 模式 | 关键结论（如「建议买入」）转人工审核 |
| 追踪/评估 | Strands tracing + Eval | 查多 Agent 调顺序、测漏查 |

---

## 路线推进顺序（推荐）
1. **主线 1 MVP** —— 先跑通 RAG 底座，学会切片/Embedding/向量库/Hook（概念全部落地）
2. **主线 2 数据层 + 指标** —— 锻炼纯工程能力，产出可复用函数
3. **主线 3 编排** —— 把前两条线的函数挂成 tool，Strands 一把串起来
4. 回头给主线 1 加 **重排 / 多模态 / Eval**
5. 主线 2 加 **回测 + 看板**

## 关键复用关系（三条线不是孤岛）
- 主线 1 的 `retrieve` 工具 = 主线 3 的「财报专家」
- 主线 2 的 行情/指标函数 = 主线 3 的「股价专家」+ 主线 2 看板本体
- 三者共享 模型层 + Strands

> 简历故事：「从单点 RAG → 数据平台 → 多 Agent 系统」的递进，比三条互不相关的项目更有说服力。
